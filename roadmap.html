Plan · 6 to 8 months

From zero to interview-ready

A detailed path through the eight modules — learn deeply, build projects, write everything down, and drill the questions that actually show up in ML / GenAI interviews.

This roadmap assumes ~12–15 hours a week (stretch to ~20 if you can). The rule that makes it stick: every major concept becomes a short write-up on this site plus one runnable notebook. If you skip writing, you will not retain it at interview depth.

By month 6–8 you should be able to: explain any core idea in plain English, implement small experiments (sklearn + PyTorch), answer ML / DL / LLM questions with tradeoffs, walk through 1–2 portfolio projects, and handle a light GenAI system-design round.

Weekly template

Repeat every week:

Learn     40%   one concept deeply
Build     30%   notebook or project slice
Write     15%   publish on this site
Drill     15%   interview Q&A out loud, timed

Drill bank: Interview questions — answer five per week in writing.

Phase 0 — Foundations Weeks 1–3 · Modules 1–2

You may already have most of this live. Treat it as a refresh until you can teach it.

  • Supervised / unsupervised / RL — with LLM analogies (pretrain, fine-tune, RLHF)
  • Train / val / test, leakage, metrics (accuracy, F1, ROC-AUC, R², RMSE)
  • Bias–variance and overfitting — reproduce the taxi experiment
  • Linear & logistic regression — loss + gradient step intuition
  • Trees, bagging, boosting — when each wins on tabular data

Checkpoint: explain overfitting and bagging vs boosting on a whiteboard in under five minutes.

Module 1 · Module 2 · Foundation interview Qs

Phase 1 — Deep Learning core Weeks 4–8 · Module 3

  • Week 4 — Neurons, layers, activations, loss. Publish / revisit Module 3. Derive one forward pass by hand.
  • Week 5 — Backprop + gradient descent. Tiny NumPy net; compare to sklearn MLP.
  • Week 6 — CNNs. Fashion-MNIST or CIFAR-10 in PyTorch; explain conv / pool.
  • Week 7 — Dropout, batch norm, learning rates, early stopping — ablate one.
  • Week 8 — RNN intuition (light); why attention replaced them.

Project A: image or tabular classifier with clean splits, metrics, and a short failure write-up.

Checkpoint: derive backprop for a 2-layer net; explain vanishing gradients and residuals.

Tools: Python, NumPy, pandas, matplotlib, scikit-learn, PyTorch.

Module 3 · Deep learning interview Qs

Phase 2 — NLP → Transformers → LLMs Weeks 9–16 · Modules 4–5

Weeks 9–11 — NLP & tokenization

  • Bag-of-words / TF-IDF → why they fail for meaning
  • Embeddings intuition; what a token is; BPE and vocab tradeoffs
  • The sequence problem: predict the next token

Weeks 12–14 — Transformers (Module 4)

  • Self-attention (Q, K, V) — compute a tiny 3-token example by hand
  • Multi-head attention, positional encoding
  • Encoder vs decoder vs encoder–decoder; GPT-style vs BERT-style
  • Notebook: a minimal transformer block in PyTorch

Weeks 15–16 — LLMs in practice (Module 5)

  • Pretraining vs SFT vs preference tuning (RLHF / DPO)
  • Prompting, few-shot, chain-of-thought — what actually helps
  • RAG: retrieve → context → generate; failure modes
  • Hallucinations and evaluation caveats

Project B (highest interview signal): RAG over your own notes/blog — chunking, embeddings, retrieval, citations, and a 20-question eval set.

Checkpoint: whiteboard attention, next-token training, and RAG in one sitting.

LLM / GenAI interview Qs

Phase 3 — Data & MLOps Weeks 17–22 · Modules 6–7

Data & features (Module 6)

  • Missing values, encoding, scaling, preprocessing leakage
  • Time-based splits; class imbalance; label noise
  • Feature importance / SHAP intuition for explainability rounds

MLOps & deployment (Module 7)

  • Serve a model (e.g. FastAPI); experiment tracking
  • Monitoring: data drift, concept drift, latency, cost
  • LLM ops: prompt versions, eval harness, guardrails, caching

Project C: deploy Project A or B; document how you’d know it’s rotting in production.

Checkpoint: five-minute answer to “How do you put this in production and detect decay?”

Portfolio projects

  • A — Classic / DL experiment — clean metrics + failure analysis (Phases 0–1)
  • B — RAG or LLM app — with an eval set (Phase 2) — do not skip this for GenAI roles
  • C — Deployed slice — API + monitoring notes (Phase 3)
  • D — System-design write-ups — short posts for Module 8 designs

Math you actually need

Do this alongside Phases 1–2 (2–3 hrs/week) — not as a two-month prelude.

  • Linear algebra — vectors, matrices, dot products (attention is dots)
  • Probability — expectation, conditionals, Bayes intuition
  • Calculus — derivatives and the chain rule (backprop)
  • Stats — mean/variance, distributions at a high level

6-month vs 8-month

6 months (aggressive)
  Phases 0→1→2→3, then ~4 weeks of interviews
  Projects A + B required; C light
  Math: intuition-heavy

8 months (recommended for “everything in detail”)
  Full Phase 4 with more reps
  Projects A + B + C polished
  Light linear algebra / probability refresh
  Read one transformer implementation carefully
