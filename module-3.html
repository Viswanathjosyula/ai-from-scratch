Module 03 · Deep Learning

The same ideas — stacked until they get smart

Neural networks and backpropagation: how weighted sums, a little non-linearity, and "nudge the weights downhill" become the engine behind modern AI.

Module 2 ended with a map: tabular data → classic ML; images, text, audio → deep learning. This module is the bridge. A neural network is not a new species of magic — it is logistic regression stacked on logistic regression, with a twist that lets it draw curves classic models cannot.

One neuron, then a layer

A single neuron does three things:

1. Take inputs. 2. Multiply each by a weight and add a bias (a weighted sum — the same idea as linear/logistic regression). 3. Pass the result through an activation — a small bend, like ReLU (max(0, x)) or a sigmoid S-curve.

One neuron alone is basically logistic regression. The leap is stacking many of them into a layer, then stacking layers. Each layer's outputs become the next layer's inputs. Early layers learn simple pieces; later layers compose them into richer ideas — edges → shapes → digits, or sounds → phonemes → words.

The activation is the load-bearing trick. Without it, a stack of linear layers collapses into one linear layer. The bend is what lets the network draw curved, nested decision boundaries.

How it learns: loss, gradients, backprop

You pick a loss — a number that says "how wrong am I right now?" For classification, cross-entropy is the usual choice (low when the predicted probability for the right class is high).

Then you nudge every weight a tiny step that reduces that loss. The direction of the nudge is the gradient — calculus's answer to "which way is downhill?" Doing this repeatedly is gradient descent.

Backpropagation is just an efficient way to compute those gradients through a deep stack: start at the loss, walk backward through each layer, and ask "how much did this weight contribute to the error?" Chain rule, applied at industrial scale. That is the whole trick behind training GPT-sized models — same idea, more layers, more data, more compute.

The result that teaches the most

Classic ML draws straight (or piecewise-straight) boundaries. A neural net can curve. I put that to a brutal test: two interlocking rings of points (make_circles in scikit-learn). No straight line can separate them. A logistic regression — Module 2's classifier ancestor — is almost helpless. A tiny multilayer perceptron (MLP) with two hidden layers is not.

model                  train acc   test acc
Logistic Regression      0.607      0.563   ← barely above a coin flip
MLP (32 → 16 hidden)     0.959      0.907   ← the curve-drawer wins

Synthetic data, fixed seed — you'll get the same two accuracy numbers.

That ~34-point gap is the whole point of deep learning in one screenshot: when the pattern is non-linear, stacking neurons with activations lets the model invent the curves it needs. Logistic regression cannot invent them; it can only draw a line.

On tabular data, remember Module 2 — gradient boosting often still wins. Neural nets earn their keep on unstructured data (images, text, audio) and on problems where the decision boundary is curved or compositional. Pick the tool for the shape of the problem.

Try it yourself

from sklearn.datasets import make_circles
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.neural_network import MLPClassifier
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline

X, y = make_circles(n_samples=1000, noise=0.15, factor=0.5, random_state=42)
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.3, random_state=42)

for name, m in [
    ("logistic", LogisticRegression(max_iter=1000, random_state=42)),
    ("mlp", MLPClassifier(hidden_layer_sizes=(32, 16), max_iter=1000, random_state=42)),
]:
    pipe = make_pipeline(StandardScaler(), m)
    pipe.fit(Xtr, ytr)
    print(name, round(pipe.score(Xtr, ytr), 3), round(pipe.score(Xte, yte), 3))

Why this unlocks GenAI

An LLM is a very deep neural network with a special layer type called attention (Module 4). Everything else you just learned still applies: weights, activations, a loss (next-token prediction), gradients, backprop. Pretraining is gradient descent on a mountain of text. Fine-tuning is the same process on a smaller, sharper dataset. RLHF adds a reward signal on top.

Once you can say "a transformer is a deep net trained with backprop to predict the next token," the mystique drops — and the interview answers get sharper.

Interview questions

What does an activation function do, and why do we need one?

It adds a non-linearity after the weighted sum. Without it, stacked layers collapse into a single linear transform and cannot model curved boundaries. ReLU is the common default: simple, sparse, and trains well.

Explain backpropagation in one breath.

Compute the loss, then use the chain rule to push gradients backward through each layer so every weight learns how much it contributed to the error — then take a small step downhill (gradient descent).

When would you still prefer gradient boosting over a neural net?

Structured/tabular data, smaller datasets, tight latency budgets, or when you need strong out-of-the-box baselines. Deep nets shine on unstructured, high-dimensional inputs where compositionality matters.

What is the vanishing gradient problem?

In very deep stacks, gradients can shrink toward zero as they flow backward, so early layers stop learning. Mitigations: ReLU, residual connections, better init, normalization — all of which show up in modern transformers.
