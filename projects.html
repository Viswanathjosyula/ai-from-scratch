Why one spine beats random demos

Random notebooks prove you watched a tutorial. A product that accumulates features proves you can design, ship, evaluate, and revisit — which is what ML / GenAI interviews actually probe.

ScratchCoach uses this website as its world: the curriculum you write becomes the data the system learns from and retrieves over. Learning and building stay the same loop.

Flagship: ScratchCoach

What it is: a study companion for the AI-from-scratch curriculum — baselines and experiments early on, then a vision slice, then a RAG tutor over the live modules, then a deployed API with evals and monitoring.

What you can say in an interview: “I built an end-to-end learning product while teaching myself AI. Here’s the classic-ML baseline, the neural net, the RAG stack, the eval set, and how I’d know it’s rotting in production.”

Audience   you (and later, readers of this site)
Data       modules, notebooks, interview bank on this repo
Output     labs → tutor chat → API → monitored service
North star answer curriculum questions with citations + honest “I don’t know”

Milestones M0 → M3 (covers all topics)

M0 — Lab Bench Phase 0 · Modules 1–2 · Weeks 1–3

Package the Module 1–2 experiments into a tiny “lab bench” inside ScratchCoach: run overfitting curves and the taxi bake-off from a simple UI or CLI, log metrics to a table, and write a one-page “how to read these charts” note.

Topics covered Mod 1Mod 2
Train/test, metrics, overfitting, baselines Phase 0Drill
Linear / trees / forest / boosting bake-off LessonDrill

Done means: reproducible script + logged metrics + short write-up on this site.

M1 — Vision slice Phase 1 · Module 3 · Weeks 4–8

Add a deep-learning lab: Fashion-MNIST (or CIFAR-10) classifier in PyTorch with a real training loop — train/val curves, dropout/augmentation ablation, and a confusion matrix. Optional: compare to a sklearn MLP on a toy non-linear set (your circles experiment).

Topics covered Mod 3Phase 1
MLP, activations, backprop, optimizers, regularisation, CNN LessonDrill

Done means: training script, saved checkpoint, metrics table, failure analysis post.

M2 — Curriculum RAG tutor Phase 2 · Modules 4–5 · Weeks 9–16

The portfolio centrepiece. Ingest this site’s HTML modules → chunk → embed → retrieve → generate answers with citations back to module sections. Build a fixed eval set of ~20 questions (from the interview bank) and score retrieval + answer quality.

Topics covered Phase 2LLM drills
Tokenization, embeddings, attention (conceptual), RAG, hallucinations, eval Mod 4–5Drill

Done means: working Q&A over the curriculum, citation links, eval spreadsheet, write-up of failure modes (bad chunks, missed retrieval, invented facts).

M3 — Ship & watch Phases 3–4 · Modules 6–8 · Weeks 17–32

Wrap ScratchCoach behind an API, version prompts/indexes, add a tiny monitoring dashboard (latency, cost/tokens, thumbs-up/down, eval regressions), and publish a system design page: requirements → data → model/prompt → eval → serve → monitor.

Topics covered Phase 3Phase 4
Leakage-aware data, serving, drift, canary, RAG system design MLOpsDesign

Done means: deployed endpoint, runbook, design write-up on this site, demo script for interviews.
